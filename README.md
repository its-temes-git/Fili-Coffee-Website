# ☕ Fili Coffee — Addis Ababa's Finest Specialty Coffee

A premium, interactive showcase website for **Fili Coffee**, crafted to deliver a modern, sensory digital experience reflecting the heritage of single-origin Ethiopian coffee.

Features fluid, momentum-based scrolling, WebGL interactive particle fields, and dynamic scroll-driven micro-animations that represent the art of specialty brewing.

---

## ✨ Features

- **⚡ Interactive Particle Field**: A dynamic WebGL particle field built with **Three.js** that responds to mouse movements, creating a warm, ambient coffee-themed aura in the hero section.
- **🌀 Dynamic Scroll Animations**: Custom **GSAP (GreenSock)** & **ScrollTrigger** animations that translate, rotate, and scale elements (like the signature roast coffee bag) as you move down the page.
- **🛡️ Lenis Smooth Scroll**: Fluid, momentum-based scroll container integration ensuring standard-defining physics across browsers and devices.
- **📱 Infinite Horizontal Product Marquee**: Auto-scrolling infinite product slider for signature offerings, with hover-to-pause and active-scaling card interactions.
- **☕ Custom Coffee-Themed Typography**: Elegant font pairing using Google Fonts: _Cal Sans_, _Goldman_, _Outfit_, and _DM Sans_.
- **🎨 Curated Palette**: A harmonious, premium design system built around a rich HSL coffee palette (latte creams, roasted browns, and vibrant warm oranges).
- **📍 Branch Location Guides**: Interactive section highlighting the _Mexico_ and _Lafto_ branches in Addis Ababa, complete with hours, contacts, and custom styles.

---

## 🛠️ Built With

- **Markup**: HTML5 (Semantic Structure)
- **Styling**: Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid, Glassmorphic overlays)
- **Logic & Canvas**: Vanilla JS (ES6+), Three.js (WebGL renderer)
- **Animations**: GSAP 3 (GreenSock), ScrollTrigger, Lenis (Smooth Scroll), Anime.js

## 🚀 Local Setup

To run this project locally, simply clone the repository and open `index.html` in your browser:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/its-temes-git/Fili-Coffee-Website
   ```
2. **Navigate to the project directory:**
   ```bash
   cd "Fili Coffee Website"
   ```
3. **Open index.html:**
   - Double-click `index.html` to run directly, or
   - Run using VS Code's **Live Server** extension for real-time auto-reload support.

## 🌎 Deployment

You can host this website easily for free using:

- **GitHub Pages**: Go to **Settings > Pages** in your GitHub repository, choose the `main` branch, and click **Save**.
- **Vercel** / **Netlify**: Connect your repository directly for instant builds and automatic deployments on every push.
